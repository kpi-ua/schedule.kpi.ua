# Contributing

Thank you for your interest in contributing to the open source projects of Igor Sikorsky Kyiv Polytechnic Institute!

## How to contribute

- Fork the repository and create a feature branch for your change.
- Keep changes focused: one pull request per logical change.
- Make sure the project builds and the linters pass before opening a pull request.
- Reference the related issue or ticket in the pull request description.
